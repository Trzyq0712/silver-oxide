# silver-oxide — progress summary (Wed 2026-05-27 10:00 → Wed 2026-06-03)

35 commits, ~+5.0k / −3.4k lines across 66 files. Test suite grew to **69 passing** lib tests.
The verifier moved from "IR plumbing" to **end-to-end verifying small Viper programs via equality
saturation**, with a usable debug visualization and a first benchmark vs Silicon.

## 1. IR / VMIR foundations (28–29 May)
- Refactored VMIR around an `InstContext` trait with **extension slots** (`InstExt`/`PureExt`/
  `HeapExt`), so method bodies and resource bodies share one instruction type but differ in which
  variants are legal. Resources can `heap sub`; `perm` is method-only.
- Settled the **resource calling convention**: callers pass a context heap; resources/functions
  read it (reserved `HeapVal::Temp(0)` ctx slot).
- Field support in translation; disambiguated fields from ADT destructors; removed the old
  translation infra. Reworked VMIR `Display` (avoiding HRTB pitfalls; omit empty path conditions).

## 2. Verification backend bring-up (31 May)
- **Typed the egg `Symbolic` language** (nodes carry `Type`); constant folding for `eq`/`lt`;
  type-aware `Binary` matching.
- First **structural rewrite rules**; **PC-aware proving** (`prove_under_pc`) and **chunk merging**
  with the agreement axiom decoupled from the operational value pick; proven equalities propagated
  into congruence. Path conditions threaded through translation.
- Verification order derived from a stored **dependency graph** (toposort; ready for parallelism).

## 3. Frontend feature coverage (01–02 Jun)
- **Fixed permission doubling** in method `@ensures` lowering (the ensures delta was accumulated
  onto the precondition heap; now produced-only).
- **Self-contained resource verification**: each resource is checked once in isolation (fresh
  e-graph, parametric ctx heap) with side-condition obligations (`acc perm ≥ 0`, `div ≠ 0`); method
  resource calls became **atomic** (no longer stepped through for the user).
- Lowered **inline `inhale`/`exhale`**, **`x := new(f1, f2)`** (full permission to listed fields),
  and **`perm(loc)`** — with Viper-faithful exhale semantics (accs subtracted left-to-right, so a
  `perm` sees the running heap while value reads use the pre-exhale heap; the `HeapCtx`/`SpatialMode`
  machinery). Source-level **`assert`/`assume`**, where any `acc(x.f, p)` becomes `perm(x.f) >= p`.

## 4. Tooling & developer UX (01–02 Jun)
- **Per-instruction e-graph + heap visualization**: one multipage PDF per method/resource (variable
  page sizes), each page annotated with the instruction, type-colored e-classes, const-fold values,
  resolved function names, produced-node highlight. Method resource calls show only their end effect;
  resources get their own stepped PDFs. (Gated by `SILVER_OXIDE_VIZ=<dir>`.)
- **Better error messages**: failures wrapped in `VerifyError::AtInst` rendering the VMIR
  instruction; explicit read-needs-positive-permission check on `Deref`.
- **Declarative rewrite-rule DSL** (`Pat` builder) — each egg rule is now a one-liner; added
  `ite(c,true,false)⇒c` and `ite(c,c,false)⇒c`, which let the `under_pc` case verify by equality
  reasoning alone.
- **Pipeline phase timings** (`run_file_timed`, printed by the verifier); permission (`Real`)
  literals now display as fractions (`1/1`, `1/2`, `0/1`).

## 5. Evaluation vs Silicon (02–03 Jun)
On `cases/inhale_exhale.vpr` (3 methods; identical verdict to Silicon: 2 pass, 1 intended fail):
- **silver-oxide**: ~**1.2 ms** verification, < 10 ms wall, ~4 MB — equality saturation only, no Z3.
- **Silicon via ViperServer (warm JVM, built from `viperserver` master)**: ~**0.52 s** verification.
- **Silicon standalone**: ~3.75 s.
- One do-nothing **Z3 process spawn ≈ 14.5 ms** (measured from a Rust binary, `z3probe`) — already
  ~12× silver-oxide's whole verification; the egg path issues zero solver calls here.
- → ~**430×** faster than warm Silicon, ~80× less memory **on this tiny program**. Caveat: the gap
  is fixed-overhead-dominated and will compress on larger inputs; this is the best case for the
  hypothesis (no Z3 fallback exercised). Details in `benchmark_inhale_exhale.md`.
- Set up the toolchain: built Silicon and `viperserver` (master) from source under JDK 17 (JDK 25
  breaks their sbt/Scala build).
